# Бот для оценки напитков 🥤

Telegram-бот, в котором можно оценивать напитки по шкале от 1 до 10, писать отзывы и собирать тир-листы:

- **общий тир-лист** — его ведут админы;
- **личный тир-лист** — у каждого пользователя свой.

Написан на Python, [aiogram 3](https://docs.aiogram.dev/) и SQLite.

## Что умеет

| Команда | Что делает |
|---|---|
| `/add` | добавить напиток (название и категория); можно сразу: `/add Добрый Кола` |
| `/drinks` | все напитки с листанием по страницам |
| `/search кола` | поиск по названию и категории |
| `/top` | топ-10 по средней оценке |
| `/mytier` | мой тир-лист картинкой |
| `/tier` | общий тир-лист картинкой |
| `/myid` | показать свой Telegram id |
| `/cancel` | отменить текущее действие |
| `/deldrink 12` | удалить напиток (только админы) |

В карточке напитка есть кнопки: «⭐ Оценить», «✍️ Отзыв», «💬 Отзывы», «📊 В мой тир-лист», а у админов ещё «🏆 В общий тир-лист». Тиры: S, A, B, C, D, F. Каждый пользователь ставит напитку одну оценку и пишет один отзыв, повторная оценка заменяет прежнюю.

К отзыву можно по желанию приложить фото напитка: после текста бот предложит прислать снимок или пропустить шаг командой /skip. Отзывы с фото помечены 📷, а в «💬 Отзывы» под ними есть кнопка, по которой бот присылает фото. Старые базы обновляются сами при запуске.

Тир-листы бот присылает картинкой-таблицей: слева буквы тиров, справа фото напитков с названием и оценкой (в общем списке — средняя, в личном — ваша). Фото берётся из отзывов: в личном списке сначала ваше, иначе самое свежее чужое. Шрифты DejaVu лежат в `bot/fonts`, так что картинка одинаково выглядит на Windows и Linux.

Удаление: в карточке напитка можно удалить свой отзыв (оценка останется) и убрать напиток из своего тир-листа, а админ может удалить напиток целиком кнопкой «❌ Удалить напиток». Перед удалением бот переспрашивает.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости (нужен Python 3.10+):

   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и впишите токен:

   ```env
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id
   DB_PATH=drinks.db
   ```

   Свой id можно узнать, запустив бота и отправив ему `/myid`. После изменения `ADMIN_IDS` бота нужно перезапустить.

4. Запустите:

   ```bash
   python -m bot
   ```

База `drinks.db` создастся сама при первом запуске.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты прогоняют сценарии бота целиком (добавление, оценка, отзыв, оба тир-листа, права админа) без обращения к Telegram.

## Структура

```
bot/
  __main__.py      запуск бота
  config.py        настройки из .env
  db.py            база данных SQLite
  keyboards.py     inline-кнопки
  texts.py         тексты сообщений
  middlewares.py   сохранение пользователя и проверка админа
  tierimage.py     картинка тир-листа (Pillow)
  fonts/           шрифты для картинки
  handlers/
    common.py      /start, /help, /cancel
    drinks.py      напитки, оценки, отзывы
    tiers.py       тир-листы
    admin.py       команды админов
tests/
```
